# Plainrail

**Know where your project stands.**

Plainrail is a local-first cognitive developer interface that turns the project context you choose into useful guidance and controlled actions through the AI provider you choose.

Built around persistent project awareness, Plainrail helps you understand what changed, where you left off, project health, history, search, and the tools and agents working around your project.

### Built around control

- Local-first project awareness
- User-approved context
- Provider-neutral AI
- Persistent project history
- Project health and search
- Agent and tool visibility
- Controlled, reviewable actions

Plainrail is currently in development, **Beta coming soon**
